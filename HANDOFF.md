## Traps met

- GLSL: `half` is reserved; the shader failed to compile silently and only
  the console said so. Check the browser console after every shader edit.
- jsdom has no WebGL, ResizeObserver or 2D context: every effect returns
  early without them; `src/test/setup.ts` mocks `matchMedia` and
  `IntersectionObserver` only.
- Tailwind v4: section grids need `grid-cols-1` before `md:` columns or the
  implicit track expands on phones.
- Look at the page itself at 1440 and 390 before trusting any visual claim in
  this document.
- There is NO prettier config in this repo and the code is single-quoted
  with no semicolons. `npx prettier --write` applies prettier's defaults and
  rewrites every file it touches into double quotes and semicolons; it did
  that to twenty files on 22 Sep and they had to be restored from HEAD. Do
  not run prettier here; eslint is the only gate.
- A capture tool that runs Chrome headless must pass
  `--use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader` or the
  band's shader silently does not run and the still CSS strip is what gets
  photographed.

## The icon set and the brand kit (22 Sep, late)

- Every icon in `public/` regenerates from one command, so a favicon cannot
  drift from an app icon: `node scripts/og/build-icons.mjs --ground mesh
  --scale 1.7 --seed 41.1,87.9`. It writes the ICO at 48/32/16, the Apple
  touch icon, `icon-192`, `icon-512` and the two Android maskable insets.
- Two arguments carry the design and neither is free. `--scale` is the fold
  size across the box's longer side; 1.7 is the value Taylor settled on from
  a ladder, and the coordinate is normalised, so it means the same physical
  fold on a 16px tile as on a 512px one. `--seed` names which piece of the
  noise field the tile shows, because the hero rolls one on every load and an
  icon cannot. Warp, bias and time stay at the hero's own, and there is no
  blur: lowering the fold size is what settles the tile.
- `scripts/brand/build-brand-kit.mjs` regenerates the brand kit, which renders
  the band and the icon through the same shader rather than showing a still
  that approximates them. `scripts/brand/brand.test.ts` holds it to the site.
  The test does not compare the committed icon PNGs to a fresh render (that
  needs a browser, which this repo keeps out of its install on purpose); it
  holds the command the kit prints to the one the generator documents.
- Every mark in `public/brand/` is ONE path whose counters are cut by
  `fill-rule="evenodd"`. Drop that attribute and the p, the e and the o fill
  solid, which reads as a heavier weight rather than as an error. That is how
  it once shipped. The gate now fails the build on a mark drawn without it.
